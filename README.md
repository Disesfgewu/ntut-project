## **研究題目**  
「**基於 OS2D 單樣本影像偵測模型的圖片通道感測之分析與探討，並討論通道剪枝影響**」

---

## **12 週研究計畫 (含文獻依據)**
| 週數     | 研究階段                          | 研究內容 (聚焦通道感測與剪枝)                                                                                                                                                                                                                               |
|---------|-----------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 第 1 週 | 環境建置與少量影像示範            | - 建置 **OS2D + PyTorch + GPU** 環境 (依 [1])<br>- 熟悉 **ResNet-50** Backbone 特徵抽取基礎 (依 [2])<br>- 以少量影像進行單樣本偵測示範，確保 OS2D 能正常運作<br>- 初步了解支援影像與查詢影像配對方式，確認日後通道分析介面                                         |
| 第 2 週 | 小規模通道感測基礎                | - 撰寫「**通道分析程式**」：對 ResNet-50 每層特徵激活值做紀錄 (依 [1][2])<br>- 使用 **T 檢定** (依 [4]) 比較「高/低通道」激活程度，了解是否確有明顯差距<br>- 以 2~3 類別的小資料集驗證：影像不同變形/支援影像時，通道是否有對應變化                                 |
| 第 3 週 | 小規模實驗結果評估                | - 彙整第 2 週測試結果，分析高/低通道對偵測的影響力 (依 [1])<br>- 若偵測失敗或特定通道激活異常，進行誤差分析<br>- 釐清需要更大規模資料 (VOC / COCO) 蒐集更多通道訊息的必要性                                                                                   |
| 第 4 週 | VOC/COCO 資料集大規模通道分析     | - 導入 **VOC 或 COCO** (官方訓練集/驗證集) 進行大規模通道感測 (依 [1])<br>- 使用先前的通道分析程式，對多類別 (query, support) pair 做批次紀錄<br>- 收集各通道激活值分布，檢驗其對多數場景/類別的貢獻度                                                                 |
| 第 5 週 | 生成式 AI 擴增與多樣影像測試      | - 利用 **GAN 或 Diffusion** 生成特定類別之合成影像，檢查通道激活與偵測效能 (依 [4] 做統計)<br>- 觀察「真實 vs. 生成」影像中通道是否具一致激活模式<br>- 蒐集異常案例做後續剪枝判斷依據                                                                                          |
| 第 6 週 | LCP 設定通道剪枝依據          | - 參考 LCP 通道篩選方法 (依 [3])<br>- 透過第 4~5 週資料蒐集，確定「冗餘通道候選 vs. 關鍵通道」<br>- 規劃「一次性剪枝 / 逐次剪枝」並記錄不同剪枝比例 (如 10%, 20%, 30%)                                               |
| 第 7 週 | 實作 L1 剪枝與初步測試            | - 撰寫 **PyTorch 結構化剪枝** 程式，依 **LCP channel selector** 由低到高排序移除 (依 [3])<br>- 先於較小批量資料檢查能否正常 forward<br>- 視需要調整剪枝比例，避免過度剪枝導致模型崩潰                                                                                  |
| 第 8 週 | 剪枝後微調 (Fine-tuning)          | - 將剪枝後模型在 **VOC/COCO train** 做微調 (依 [1])<br>- 紀錄微調前後的 **mAP、推論速度(FPS)、參數量**<br>- 若精度下跌過多，嘗試降低剪枝量或增加微調 epoch 次數                                                                                        |
| 第 9 週 | 剪枝模型多場景驗證與分析          | - 在 **VOC/COCO val** / 測試集檢驗剪枝後之 mAP、速度增益 (依 [1])<br>- 再次使用前期生成影像 / 變形影像測試：觀察剪枝後偵測穩健度是否受到影響<br>- 總結各組剪枝比例：10% / 20% / 30% / baseline 的差異                                                                        |
| 第 10 週 | 通道分析結果回顧與 ODVA 參考       | - 回頭比對「剪枝前後」關鍵通道的激活值，探討 OS2D 與 **ODVA** [7] 在 One-Shot 機制上是否有可參考之處<br>- 若時間允許，可考慮小規模導入 ODVA 所述之注意力概念，觀察對通道選擇影響<br>- 仍維持研究主題：探討「圖片通道感測與剪枝影響」                                                  |
| 第 11 週 | 量化 (Quantization) 與報告草稿    | - 將「最佳剪枝模型」嘗試 **FP16 / INT8** 量化 (依 [5][6])<br>- 測量推論速度與 mAP 變化，討論是否具備實務加速價值<br>- 開始撰寫報告初稿：彙整通道感測、剪枝策略與量化實驗結果                                                                           |
| 第 12 週 | 總結 & 未來發展                   | - 整合最終實驗圖表：通道激活度、剪枝前後 mAP、量化差異<br>- 討論「L1 norm 剪枝對 OS2D 單樣本偵測模型」的利弊與限制 (依 [1][3])<br>- 根據 ODVA [7] 或其他 One-Shot 研究提出未來延伸構想<br>- 完成專題論文定稿，聚焦本研究主題之完整發現與結論                                      |

### **文獻對應 (參考編號與意涵)**

1. **A. Osokin et al. (2020)**  
   - **OS2D: One-Stage One-Shot Object Detection by Matching Anchor Features**  
   - [arXiv:2003.06800](https://arxiv.org/abs/2003.06800)  
   - **說明**：本研究 OS2D 架構之主要參考，掌握 One-Shot 偵測流程與實驗評估方式。

2. **K. He et al. (2016)**  
   - **Deep Residual Learning for Image Recognition**  
   - [arXiv:1512.03385](https://arxiv.org/abs/1512.03385)  
   - **說明**：OS2D 所使用的 ResNet-50 主架構出處，需理解殘差網路之特徵抽取行為。

3. **H. Li et al. (2017)**  
   - **Pruning Filters for Efficient ConvNets**  
   - [arXiv:1608.08710](https://arxiv.org/abs/1608.08710)  
   - **說明**：L1 norm 通道剪枝的核心理論與實作依據；本研究之剪枝策略主要參考此作法。

4. **M. Fordellone et al. (2018)**  
   - **Structural Equation Modeling and simultaneous clustering through Partial Least Squares**  
   - [arXiv:1810.07677](https://arxiv.org/abs/1810.07677)  
   - **說明**：支援數據分析方法，可用於 T 檢定與激活值差異性統計。

5. **B. Jacob et al. (2018)**  
   - **Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference**  
   - [arXiv:1712.05877](https://arxiv.org/abs/1712.05877)  
   - **說明**：量化 (FP16/INT8) 對推論速度與精度的影響研究。

6. **NVIDIA Developer (2023)**  
   - **Optimizing AI Inference with TensorRT**  
   - [TensorRT](https://developer.nvidia.com/tensorrt)  
   - **說明**：提供實際量化優化工具，在剪枝後可進一步用於部署加速。

7. **P.-M. Hsu (2020)**  
   - **One-Shot Object Detection Using Versatile Attentions (ODVA)**  
   - 國立臺灣大學電信工程學研究所 碩士論文  
   - **說明**：雖非本研究剪枝主軸，但在 One-Shot 偵測與注意力機制上有參考價值，可在最後做延伸討論。

## **總結重點**

1. **不偏離主題**  
   - 全程圍繞「**基於 OS2D 單樣本影像偵測模型的圖片通道感測**」與「**通道剪枝影響**」；  
   - 以 **L1 norm** 做核心剪枝方法，搭配 T 檢定驗證激活度差異之存在。

2. **一貫研究流程**  
   - 前期（第 1~3 週）用小規模資料驗證通道激活值高低；  
   - 第 4~10 週透過 VOC/COCO 及生成式影像做大規模通道蒐集與剪枝實驗；  
   - 後期（第 11~12 週）則測試量化與撰寫完整報告，最終將成果集中呈現。

3. **ODVA 參考**  
   - 雖然本研究不實際採用 ODVA 模型，但在 One-Shot 偵測機制與注意力設計上可從其論文[7] 中獲得啟發，最後一並納入未來展望。

如上規劃，可在 12 週內完成「**通道感測分析** + **L1 剪枝** + **生成式影像測試** + **量化實驗**」，並對 **OS2D 單樣本偵測**之模型效能與通道重要度產生具體討論與貢獻。祝研究順利！
