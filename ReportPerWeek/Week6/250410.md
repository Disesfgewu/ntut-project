## 🔬 Lab 10 實驗架構與目的：重新剪枝並嘗試保留結構進行微調

### 一、實驗背景  
在 Lab 9 中完成通道剪枝與模型儲存後，發現微調後模型大小回復至剪枝前，推測 OS2D 框架於初始化階段自動重建完整 ResNet50 架構，導致剪枝結構未被保留。本次實驗將針對此問題進行修正。

### 二、實驗目的  
1. 修正剪枝後模型於微調階段結構無法保留之問題。  
2. 重新實作剪枝與儲存機制，確保剪枝結構可被完整保留與載入。  
3. 重新進行微調，觀察模型精度與參數數量是否一致反映剪枝效果。  
4. 建立具備「剪枝 ➜ 儲存 ➜ 微調 ➜ 評估」的正確流程。

### 三、實驗內容與步驟  
1. **剪枝策略設計與執行**  
   - 繼續採用 L1 norm 排序作為剪枝依據，剪除前 30%、50%、80% 通道。  
   - 執行通道剪枝後，同時裁切權重與模型架構。

2. **模型儲存與初始化修正**  
   - 儲存剪枝後完整模型架構（非僅 `state_dict`）。  
   - 修改 OS2D 初始化流程，避免重新構建完整 ResNet 結構。  
   - 若無法修改架構，考慮將剪枝後模型凍結並微調上層分類模組。

3. **微調與評估**  
   - 使用 GroZi 資料集對剪枝後模型進行微調（fine-tune）5–10 epoch。  
   - 評估剪枝比例與 mAP、參數量、模型大小之變化。

### 四、預期成果  
- 成功建立能保留剪枝結構的 OS2D 微調流程  
- 剪枝比例與模型精度呈現可觀測關係  
- 修正 Lab 9 微調模型結構回復之問題

## ⚙ Lab 10 實驗設計與流程：結構保留式剪枝與微調實作

### 一、實驗設計  

本次實驗以保留通道剪枝後的 ResNet 架構為核心目標，採用 PyTorch 原生剪枝與模型再建構流程，以確保微調階段不會重新還原剪枝結構。並驗證不同剪枝比例下的參數變化與模型大小。

---

### 二、實驗流程  

#### Step 1. **L1 norm 剪枝通道選取**  
- 對每層卷積層所有通道計算 L1 norm：  
  \[
  L1\_norm = \sum |weights|
  \]
- 依比例（30%、50%、80%）選擇最小 L1 norm 通道進行移除。

#### Step 2. **結構剪枝並儲存壓縮模型**  
- 使用自訂 `prune_channels_from_layer()` 方法，結合 `torch.fx` / 模型重建邏輯，裁切架構。  
- 儲存包含完整結構的 `.pth` 模型（非僅 `state_dict`）。

#### Step 3. **微調階段修正初始化機制**  
- 進入 `build_os2d_from_config()` 階段時，將剪枝後模型作為 backbone 直接嵌入 `net.net_feature_maps`。  
- 避免從原始架構重新建構完整 ResNet50。

#### Step 4. **評估與記錄變化**  
- 比較不同剪枝比例下之：  
  - 模型大小（MB）  
  - 參數數量  
  - mAP 表現（@0.5）

---

### 三、實作程式碼範例（Prune + Save）  

```python
import torch
import pandas as pd
import os
import copy
from os2d.modeling.model_os2d import build_os2d_from_config
from config.config import cfg  # 輸入自定義 config

# 匯入通道清單
df_final = pd.read_csv("final_prune_list.csv")
example_input = torch.randn(1, 3, 224, 224).to("cuda")

# 載入原始 OS2D 模型
cfg.init.model = "./resnet_before_prune.pth"
net, _, _, _, _ = build_os2d_from_config(cfg)
backbone = net.net_feature_maps

# 執行剪枝（需定義好 prune_channels_from_layer 方法）
prune_channels_from_layer(backbone, df_final, example_input)

# 壓縮後模型建立與儲存
compressed_model = copy.deepcopy(backbone).cpu()
torch.save({"net": compressed_model}, "resnet_after_real_prune_0_8_full.pth")
```
