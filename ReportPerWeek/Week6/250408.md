## 🔬 第六週實驗設計：L1 norm 設定通道剪枝依據

### 一、實驗目的  
本週目標為應用 L1 norm 作為通道重要性評估指標，建立初步的通道剪枝策略，並驗證剪枝比例與模型效能間的關係。

### 二、文獻依據  
參考 H. Li et al., *Pruning Filters for Efficient ConvNets*（ICLR 2017），提出以每個通道的 L1 norm 作為篩選依據，低 L1 norm 通道視為冗餘、可剪除。

### 三、實驗步驟  

1. **通道重要性計算**  
   - 針對每一層卷積層之每個通道（filter），計算其 L1 norm：
     \[
     L1\_norm(filter) = \sum |w_i|
     \]
   - 將同層通道依 L1 norm 由小到大排序。

2. **通道篩選與比對**  
   - 結合第 4～5 週所蒐集之通道活化資料與異常通道紀錄，驗證是否與 L1 norm 低值通道對應。
   - 區分：
     - 冗餘通道候選（低活化 & 低 L1 norm）
     - 關鍵通道（高活化或高 L1 norm）

3. **剪枝策略設計**  
   - **一次性剪枝（One-shot Pruning）**：  
     - 對模型進行一次性剪枝，分別剪除最低 L1 norm 通道的前 10%、20%、30%。
   - **逐次剪枝（Iterative Pruning）**：  
     - 每輪剪除 5% 最低 L1 norm 通道，逐輪觀察模型精度與推論時間變化，直到達 30%。

4. **模型訓練與微調**  
   - 剪枝後的模型進行微調（Fine-tuning）5~10 個 epoch，以穩定剪枝後性能。

5. **評估與記錄**  
   - 針對不同剪枝比例與策略，記錄以下指標：
     - Top-1 Accuracy（準確率）
     - 模型參數數量
     - 推論時間（ms/frame）
     - 模型大小（MB）

### 四、預期成果  
- 建立以 L1 norm 為基礎的剪枝框架  
- 評估不同剪枝比例下的效能變化  
- 初步定義通道篩選的有效依據

### 三、問題分析與補充說明

> 儘管在剪枝後模型大小明顯下降，但微調後模型回復原始大小，推測為框架重新建立 ResNet50 架構並補齊缺失權重所致，實際並未保留剪枝結構，後續將嘗試修改初始化流程以保留精簡結構。

目前推測 `OS2D` 的初始化邏輯會根據 YAML 配置重新建立完整模型，並將 `.pth` 權重補齊，因此導致剪枝結構未生效。建議後續採用以下改進策略：

- 🛠 將剪枝後的模型儲存為完整模型架構（非僅 `state_dict`），或
- 🛠 改寫 `build_os2d_from_config()` 函式，讓其能讀取剪枝後模型並不還原結構。
